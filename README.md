This mod lets you multiply the stack size of items.

- General multiplier, applied to specified Item Types and Item Names (internal) 
- Both Item Types and Item Names can be specified with a multiplier specific to each.

Enter Items types to be modified, with format: 'item_type=stack_size'\nEntries separated by comma. \n'stack_size' is optional, if omitted will use multiplier above.\nItem names overwrites Item types, which overwrites the general multiplier.\nYou can check item name, type, weight and a lot more while mouse-over in game and pressing CTRL + SHIFT + F.
